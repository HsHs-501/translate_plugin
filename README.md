## 📖 What is this?

Ever get tired of copying messages, opening a browser or translation app, and then going back to Discord? **Translate Plugin** solves this by adding a native translation option directly into your Discord app. Now you can seamlessly read messages in other languages instantly.

---

## ✨ Features

- 🌍 **Inline Translation**: Translate any message natively within the chat view without leaving Discord.
- 🖱️ **Context Menu Integration**: Adds a seamless "Translate" button straight into the native Discord message context menu.
- ⚙️ **Language Customization**: Choose your preferred "Translate from" and "Translate to" languages directly from the plugin settings, or use Auto-detect.
- ⚡ **Lightweight & Fast**: Optimized for speed so it won't lag your client or slow down your app.
- 🚀 **Zero Build / No Bundler**: Built in plain ES2019 IIFE format for Revenge Classic.
- 🛡️ **Safe & Stable**: Seamlessly integrates into the Discord UI without breaking core app functions.

## 📱 How to Use

1. Open any server or direct message.
2. Long-press the message you want to translate.
3. Tap the **Translate** button in the pop-up context menu.
4. The translated text will appear instantly!

---

## 📥 Installation

To install this plugin in **Revenge** on Discord (Android):

1. Copy the plugin URL:
   ```text
   https://hshs-501.github.io/translate_plugin/manifest.json
   ```
2. Open Discord and go to **User Settings** (your profile icon).
3. Scroll down to the **Revenge** section and tap **Plugins**.
4. Tap the **`+`** (Install Plugin) button at the top right.
5. Paste the plugin URL and confirm the install.
6. The plugin will load automatically into your client. You can start translating messages right away!
