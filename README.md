# Revenge Translate Plugin

Hey! I built this translator plugin for the Revenge Discord client on Android because I was tired of switching apps just to read messages in other languages. This lets you translate everything directly inside your chat view.

## What it does
* Translates messages instantly without ever leaving Discord.
* Adds a simple "Translate" option straight into the native message context menu.
* Stays super lightweight so it won't lag your client.

## How to install it
1. Open the Revenge app and head into your **User Settings**.
2. Scroll down to the **Revenge** section and tap on **Plugins**.
3. Tap the add icon to fetch a new plugin via URL.
4. Paste the raw link to the plugin file from GitHub (make sure to use the raw format, like `https://raw.githubusercontent.com/HsHs-501/translate_plugin/main/yourfile.js`).
5. Toggle the switch to enable it, then restart your app to apply the changes.

## How to use it
Just long-press any message in a server or DM and tap the new **Translate** button that pops up. 

If you run into any bugs or have ideas to make it better, feel free to drop an issue on the [GitHub repository](https://github.com/HsHs-501/translate_plugin).
